# CME — Centre for Multidisciplinary Education, IIT Bombay

A modern, thorough website for the **Centre for Multidisciplinary Education (CME)** at IIT Bombay
(formerly the Centre for Liberal Education, CLE).

It's a fast, fully self-contained **static site** generated by a small Python static-site
generator, so it will run and deploy anywhere — no Node, no runtime dependencies, no external
calls in the browser (fonts, logos and images are all hosted locally for speed and visitor privacy).

## What's inside

Nine pages, each built from the source materials in `imp-files/`:

| Page | What it covers |
|------|----------------|
| **Home** (`index.html`) | The idea, headline stats, why CME, foundation preview, concentrations, featured seminars, recruiters, faculty |
| **About** | The idea & philosophy, CLE → CME history, who it's for, honest trade-offs, leadership |
| **Curriculum** | Six foundation baskets (with real course codes), the Sem 3–8 credit map, credit rules, seminars → projects |
| **Concentrations** | The four BS degrees — Engineering, Natural, Social Sciences, Art & Design — and minors |
| **Faculty** | The full IDPC Team 2026 (12 faculty, with photos) + the Faculty Advisor system |
| **Students** | Featured seminars + a searchable/filterable directory of all 27 students and their seminar topics |
| **Placements** | Internship stats, a prestige-ranked recruiter wall, role breakdown, higher-studies angle |
| **Admissions** | Eligibility, the 4-step process & timeline, reassurances, and an honest FAQ |
| **Contact** | Faculty in-charge, location, quick links |

### Design
- **Type system** (self-hosted): Fraunces (editorial display serif) · Inter (body) · Space Grotesk
  (brand + numbers) · JetBrains Mono (labels).
- **Light + dark themes** with a toggle (respects the OS preference, remembers your choice).
- A **six-hue "multidisciplinary spectrum"** motif — one colour per foundation area — running through
  the brand mark, section accents and the curriculum.
- Scroll-reveal animations, animated counters, a searchable student directory, and an FAQ accordion,
  all in **dependency-free vanilla JS**.

## Project layout

```
dept-web/
├── venv/                    # Python virtual environment
├── requirements.txt         # build-time Python deps (asset processing only)
├── serve.py                 # build + local server
├── imp-files/               # source material (PDFs, seminar xlsx) — input
├── scripts/
│   ├── build.py             # the static-site generator (entry point)
│   ├── parse_data.py        # parses the seminar xlsx → data.json
│   ├── data.json            # generated consolidated student data
│   └── sitegen/             # generator package (data, components, icons)
└── site/                    # ← the generated website (deploy this folder)
    ├── *.html
    └── assets/{css,js,fonts,img}
```

## Running it

Everything runs inside the included **virtual environment**.

```bash
cd "dept-web"
source venv/bin/activate          # Windows: venv\Scripts\activate

# 1. (only if the seminar data changes) re-parse the Excel sheet
python scripts/parse_data.py

# 2. build + serve  →  http://localhost:8000/index.html
python serve.py

# build only (no server):
python serve.py --build
```

To edit content, change the data in `scripts/sitegen/data.py` (or `parse_data.py` for students),
then rebuild with `python serve.py`.

## Deploying

The `site/` folder is a complete static website. Upload its contents to any web host
(the IIT Bombay department server, GitHub Pages, Netlify, etc.). No server-side code is required.
